# IMDB Movie Reviews Dataset (для задачи бинарной классификации тональности)

## 1. Общее описание

Датасет содержит тексты отзывов на фильмы с сайта IMDB, размеченные
по тональности (позитивный / негативный отзыв). Предназначен для
обучения и оценки моделей анализа тональности текста (sentiment
analysis), в частности рекуррентных нейронных сетей (RNN/LSTM/GRU).

**Источник:** открытый датасет Stanford NLP — *IMDB Large Movie
Review Dataset* (Maas et al., 2011).
**Оригинал:** https://ai.stanford.edu/~amaas/data/sentiment/
**Зеркало:** https://huggingface.co/datasets/stanfordnlp/imdb

> Примечание: закрытое соревнование Kaggle
> `neural-university-imdb-spring2019` использовало модификацию этого
> датасета (40 000 train / 10 000 test). Данная версия — классическая
> (25 000 / 25 000), полностью совместимая по формату и пригодная
> для тех же задач.

## 2. Структура датасета

| Split          | Кол-во примеров | Назначение                       |
|----------------|-----------------|----------------------------------|
| train          | 25 000          | Обучение модели                  |
| test           | 25 000          | Оценка качества модели           |
| unsupervised   | 50 000          | Неразмеченные отзывы (для предобучения / эмбеддингов) |

Классы сбалансированы: в каждом из размеченных сплитов ровно
12 500 позитивных и 12 500 негативных отзывов.
