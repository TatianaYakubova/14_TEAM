﻿#  CineMatch - Совместный подбор фильмов

Веб-приложение для совместного выбора фильмов с друзьями на основе предпочтений всех участников.

##  Быстрый запуск

### Требования
- Docker Desktop
- Git

### Установка

  Bash
# 1. Клонируйте репозиторий
git clone https://github.com/Diana-Bashirova/cine_match.git
cd cine_match

# 2. Запустите приложение
docker-compose up --build
  

### Доступные адреса
- **Фронтенд**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **Swagger документация**: http://localhost:8000/api/schema/swagger-ui/
- **Django Admin**: http://localhost:8000/admin/

###  Тестовые аккаунты

**Администратор:**
- Логин: Admin
- Пароль: Admin123

**Обычные пользователи:**
- Логин: user1 / Пароль: qwerty123

##  База данных

Репозиторий содержит предзаполненную базу данных db_copy.sqlite3 (42 MB) с:

# Кейс 2. Анализ тональности русскоязычных отзывов

Команда 14: Баширова Диана, Баширов Артур, Якубова Татьяна, Нагорный Иван

Задача — трёхклассовая классификация тональности русскоязычных текстов:
`0 = Neutral`, `1 = Positive`, `2 = Negative`.

Модель: TextCNN на предобученных эмбеддингах Navec, гиперпараметры подобраны Optuna.

---

## 1. Датасет: `sentiment_dataset.csv`

### 1.1. Общее описание

| Параметр | Значение |
|----------|----------|
| Файл | `sentiment_dataset.csv` |
| Язык | русский |
| Формат | CSV (UTF-8) |
| Задача | 3-классовая классификация тональности |
| Число записей после очистки | **290 458** |
| Классы | Neutral (0), Positive (1), Negative (2) |
| Баланс классов | сбалансирован (см. п. 1.3) |
| Разделение | Train 80% / Val 10% / Test 10%, стратифицировано (`random_state=42`) |
| Тестовая выборка | 29 046 примеров |

### 1.2. Структура

| Колонка | Тип | Описание |
|---------|-----|----------|
| `text` | string | исходный текст отзыва |
| `label` | int | метка класса: 0 / 1 / 2 |
| `src` | string | идентификатор источника (платформы) |

Дополнительные колонки, создаваемые в ноутбуке:

| Колонка | Описание |
|---------|----------|
| `tokens` | токены после очистки (нижний регистр, только кириллица) |
| `tokens_lemma` | лемматизированные токены (pymorphy3) |
| `tokens_nostop` | леммы без стоп-слов (только для EDA) |
| `predicted_label` | предсказание модели |
| `predicted_sentiment` | предсказание в виде строки |

### 1.3. Распределение классов

### 1.5. Качество разметки

**Сильные стороны:**

- Классы сбалансированы, что снижает риск смещения в сторону мажоритарного класса.
- Данные прошли дедупликацию и удаление пропусков (`dropna().drop_duplicates()`).
- Тексты предсказуемо очищены: нижний регистр, фильтр `[^а-яё\s]`, лемматизация через pymorphy3 — единый пайплайн для train / val / test.

**Ограничения:**

- Согласованность аннотаторов (Inter-Annotator Agreement) в датасете не указана — уровень шума разметки количественно не оценён.
- Границы класса Neutral размыты: модель путает «слабо позитивные» отзывы с нейтральными (F1 = 0.60).
- Источники гетерогенны по домену (магазины, кино, аниме, банки) — единый классификатор вынужден работать на разных стилях.

### 1.6. Применимость для задачи

**Подходит для:**

- обучения baseline-моделей трёхклассовой тональности на русском;
- экспериментов с предобученными русскоязычными эмбеддингами (Navec, RuBERT);
- исследований доменной адаптации при слиянии нескольких источников.

**Не рекомендуется для:**

- продакшн-задач, где критична точность класса Neutral;
- узкодоменных сценариев (например, только банковские отзывы) — миноритарные источники представлены слабо;
- задач, чувствительных к шуму разметки, — нет данных по IAA.
